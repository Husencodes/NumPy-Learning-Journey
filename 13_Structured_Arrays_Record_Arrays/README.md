
# Day 13 - NumPy Structured Arrays

## Overview
Today I learned how to store and manage different data types
inside a single NumPy array using structured arrays.

## Topics Covered
- Creating Structured Arrays
- Defining Custom Data Types
- Accessing Individual Fields
- Modifying Fields
- Filtering Records
- Sorting Structured Arrays
- Record Arrays

## Mini Project
Student Database using NumPy Structured Arrays.

## Key Learnings
- Structured arrays store different data types together.
- Each field has a name and data type.
- Records can be filtered and sorted.
- Record arrays allow attribute-based field access.
