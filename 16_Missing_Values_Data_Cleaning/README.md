## Key Learnings
- NaN represents missing numerical data.
- np.isnan() identifies missing values.
- np.nanmean() calculates mean while ignoring NaN.
- Boolean masking helps remove or replace missing values.
- np.nan_to_num() replaces NaN and infinity.
